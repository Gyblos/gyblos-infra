# Relay deployment status

This page is the public source of truth for the intended Gyblos relay
topology. It is not a live availability monitor and does not contain host IPs,
credentials or deployment-only details.

| Relay | URL | Provider | Deployment | Status |
| --- | --- | --- | --- | --- |
| `na1` | `https://na1.relay.gyblos.com/` | Hostinger | Dokploy | Active |
| `na2` | `https://na2.relay.gyblos.com/` | To be defined | To be defined | Planned |

deployed and verified, `na1` is the only relay represented as active in the
project documentation.
